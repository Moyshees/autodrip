AutoDrip 1.21.4 (Fabric)

BUDOWANIE BEZ INSTALOWANIA NICZEGO:
1. Załóż repozytorium na github.com i wgraj do niego CAŁĄ zawartość tego folderu
   (razem z ukrytym folderem .github).
2. Wejdź w zakładkę Actions -> ostatni przebieg "build" -> Artifacts -> autodrip-jar.
3. Pobierz, rozpakuj, wrzuć autodrip-1.0.0.jar do folderu mods (razem z Fabric API 0.119.4+1.21.4).

BUDOWANIE LOKALNIE: Java 21 + Gradle 8.12+, w folderze projektu: gradle build
Jar: build/libs/autodrip-1.0.0.jar

Klawisze: V = menu, R = włącz/wyłącz.
